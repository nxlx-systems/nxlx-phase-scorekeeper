# Contributing

Thanks for your interest in Phase 10 Scorekeeper.

## Bugs and ideas

Open an [issue](https://github.com/nxlx-systems/nxlx-phase-scorekeeper/issues). The bug form asks for the app version, your device and browser. Please don't paste a backup file: it holds your players' names and scores.

## Pull requests

Small, focused pull requests are welcome. Before you start on anything large, open an issue so we can agree on it first.

- The app is one `index.html` file with plain JavaScript and no build step. Keep it that way.
- Follow [docs/RELEASING.md](docs/RELEASING.md), especially the rules that protect people's scores: the storage key and `sw.js` stay the same.
- The **Checks** workflow must pass. You can run the same checks on your own computer (see RELEASING).
- Use made-up names in screenshots and tests.
- Text people see uses Canadian spelling and plain words, and covers phones, tablets and computers rather than one kind of device.
