# Security

Phase 10 Scorekeeper runs entirely in your browser. It has no server, no accounts and no tracking, and your scores never leave your device unless you share a backup yourself.

## Reporting a problem

If you find a security problem, please report it privately with GitHub's **Report a vulnerability** button on the [Security tab](https://github.com/nxlx-systems/nxlx-phase-scorekeeper/security), rather than in a public issue. Expect a first reply within a week.

Only the latest version (the one at https://nxlx-systems.github.io/nxlx-phase-scorekeeper/) gets fixes.
